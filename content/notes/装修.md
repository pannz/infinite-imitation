乳胶漆如果想要纹理感，可以使用 rollingdog 滚动狗滚刷来刷乳胶漆，可以比较容易得到想要的纹理感，购买一个 rollingdog 套装价格大概在大几十块，不贵不必省钱。

墙面一定要平整，全屋冲筋找平最好（价格高）起码都要顺平。

墙面打磨后一定要验收，在暗环境下用光从侧面打光看是否有波浪纹等，没有打磨好的一定要叫返工。验收一定要在上漆之前。

装修大概的顺序：拆 => 中央空调 => 水电（走天）=> 网络规划部署调试 => 地暖 => 泥瓦 (地面墙面预埋) => 木工 (吊顶预埋) => 墙漆工 => 全屋定制等 => 全屋保洁 => 全屋打胶 => 全屋去醛，软装家具...

预埋很多时候既美观也实用，现在预埋件的材料使用寿命很长，只要安装预埋的时候符合施工标准，没有问题。可以预埋花洒，空调出风回风口，吊顶筒灯，灯带等，各种衔接型材，内退踢脚线，推拉门轨道，轨道插座...

全屋智能还是无脑选小米，生态无敌，产品众多，价格亲民，不要去搞别的，matter over thread 也就那样，我的评价不如小米...

全屋净水，如果要做软水，需要看下水路是否满足，应为软水软化后水中钾离子（钠离子？）就多了，是不适合饮用的，也不是很适合洗菜，所以水路入户后应该分两路，一路软水（给电器之类的用，比如热水器，花洒，马桶）一路生活用水，饮用需要加厨下净水 RO 过滤

水路不适合同时没有改水路的话我的一套配置是：
入户大白瓶（库硕水灵双联 pp+fof, fof 相当于 mini 软水），厨下净水（锐普 U8, 带零陈水装置），祁禧管线机 C638-6H 总价不到在 3.3k，使用成本估计每天 1 块多一点（主要 fof 滤芯贵，大概 300 天得换，一个两三百块钱）

不管是施工还是安装，细节很重要，比如打水平仪，水平尺，直角尺，各种钻孔拉口子，都需要专业的工具，千万避雷不依靠辅助工具配合，只考工人自己手搓（大部分手搓的丑的要命）

全屋定制，需要和设计师说好尺寸细节，各种收口要不要留，留多少等，不要花里胡哨的灯带

榻榻米最好避开，不如买成品（儿童）床
